# GitHub Projects — tablero de seguimiento

Repositorio: `juancsan10/SGP`

Columnas requeridas:

1. Backlog
2. En proceso
3. Pruebas
4. Hecho

Convención: una tarjeta por tarea y una rama por cambio. La tarjeta pasa a Pruebas cuando el PR está integrado en `develop`; pasa a Hecho después de una revisión manual realizada por otra persona del equipo.

> El tablero es un recurso externo de GitHub y debe mantenerse actualizado con cada PR.
