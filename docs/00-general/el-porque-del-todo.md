# EXPOSICIÓN DEL PROYECTO SGP-SENA

## Sistema de Gestión de Proyectos SENA

### Tecnologías utilizadas y por qué

## 1. React.js (Frontend)
- Componentes reutilizables.
- Mejor organización del código.
- Fácil mantenimiento.

## 2. Vite
- Inicio rápido del proyecto.
- Recarga automática.
- Desarrollo más eficiente.

## 3. JavaScript
- Lógica de la aplicación.
- Interactividad.
- Compatible con React y Node.js.

## 4. HTML5
- Estructura de las páginas web.

## 5. CSS3
- Diseño visual.
- Responsive Design.

## 6. Node.js (Próxima fase)
- Desarrollo del Backend.
- Creación de APIs.

## 7. Express.js (Próxima fase)
- Gestión de rutas.
- APIs REST.

## 8. MySQL (Próxima fase)
- Almacenamiento de datos.
- Gestión de usuarios, fichas y proyectos.

# Arquitectura

Frontend (React + Vite + CSS)
        |
Backend (Node.js + Express)
        |
Base de Datos (MySQL)

# Conclusión

SGP-SENA busca centralizar la gestión de proyectos formativos mediante tecnologías modernas, escalables y ampliamente utilizadas en la industria.
